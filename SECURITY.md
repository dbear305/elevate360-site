# Security policy

## Reporting vulnerabilities

For vulnerabilities in this repository, email contact@elevate360systems.com with the subject "Repository security report". This is the existing company contact address. Include the affected component and commit, reproduction steps, expected versus actual behavior, and impact. Send the minimum evidence necessary and omit credentials or unrelated personal data.

Do not publish exploitable details or confidential evidence in a public issue before coordination. Ordinary bugs and documentation improvements can use GitHub issues or pull requests.

## Maintenance scope

Report against the current default branch. Historical snapshots do not have a separate maintenance commitment. This policy does not promise response deadlines or establish a bounty program.

## Research material

Security research contribution guidance is in [the standalone Security Lab contribution guide](https://github.com/dbear305/security-lab/blob/main/CONTRIBUTING.md). Synthetic examples are explicitly labeled. Live reports should be reviewed before publication.
