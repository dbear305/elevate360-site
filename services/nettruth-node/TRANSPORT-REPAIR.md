Eight 25,000,000-byte transfers totaled 200 MB of application payload, under one existing extended-session allowance. The order was H2, H1, H1, H2, each with a download and upload.

| Protocol | Download request Mbps | Upload request Mbps |
| --- | ---: | ---: |
| HTTP/2, first | 243.19 | 143.65 |
| HTTP/1.1, first | 249.89 | 257.34 |
| HTTP/1.1, second | 249.72 | 242.85 |

## Repair and safeguards

`repair_transport.py` accepts only the stock, single-host NetTruth Caddy configuration generated by the current installer, for the exact Miami or Dallas hostname and loopback backend. It refuses shared/customized configs rather than overwriting them.

The only configuration addition is:

```caddyfile
{
    servers :443 {
        protocols h1
    }
}
```

This preserves HTTPS and certificate verification while selecting HTTP/1.1 on the dedicated measurement listener. It does not downgrade TLS or alter the Vercel website. It is a bounded workaround for the observed upload constraint, not a general recommendation to disable HTTP/2 on websites.

Without `--apply`, the script validates and exits without changing configuration. With `--apply`, it checks the existing node and proxy, validates the candidate with Caddy, backs up the original under `/var/backups/nettruth-transport`, atomically replaces the file, gracefully reloads Caddy, checks fresh TLS negotiation and health, and attempts automatic rollback if post-checks fail. It prints the backup and rollback command. No packages are installed and no machine reboot is requested.

Run it using the existing authorized root/sudo login on the measurement VPS. Do not send passwords, private keys or TURN secrets in chat. Applying on Miami does not modify Dallas. After application, close old browser connections and use a fresh tab with Miami explicitly selected for the comparison.

The installer currently recreates its original Caddyfile. Do not rerun the entire installer to apply this repair; a future installer run would require re-evaluating/reapplying this opt-in transport change.
